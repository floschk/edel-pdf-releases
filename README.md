# EDEL PDF

**EDEL PDF** is a desktop PDF editor for Windows by **EDELGRP**: view, annotate, fill and sign, edit text and images, organise pages, convert HTML to PDF and PDF to Word, and recognise text in scans.

This repository holds the installers. Installed copies of EDEL PDF check it for new versions and update themselves.

## Download

Get **`EDEL-PDF-Setup-<version>.exe`** from the [latest release](https://github.com/floschk/edel-pdf-releases/releases/latest) and run it.

Windows may show *"Windows protected your PC"* the first time, because the installer isn't code-signed yet. Click **More info → Run anyway**. Later updates install from inside the app without this warning.

To open PDFs with EDEL PDF by default, use **File → Make EDEL PDF the Default PDF App…** in the app.
